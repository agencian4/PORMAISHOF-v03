# PORMAISHOF · versão 03

Site estático (HTML, CSS e JS em um único `index.html`, imagens em `img/`). Não precisa de build.

## Publicar
- **GitHub Pages:** suba o conteúdo desta pasta na raiz do repositório e ative Pages em Settings › Pages (branch `main`, pasta `/root`).
- **Vercel:** importe o repositório; Framework Preset "Other", sem comando de build, Output Directory vazio (raiz).
